# ژورنال معاملاتی (Notebook Trade)

دفترچه معاملاتی چندکاربره با **Next.js 15 + Tailwind CSS 4**.

هر روز اول تعداد معاملاتی را که برنامه داری ثبت می‌کنی. بعد از بسته شدن هر معامله، نتیجه‌اش را وارد می‌کنی:
**TP** با ریوارد گرفته‌شده (مثلاً 3R)، **SL** یا **RF** (ریسک‌فری). استراتژی، نماد، جهت و یادداشت هم ثبت می‌شود.
بقیه کارها خودکار است: آمار، وین‌ریت، مدیریت ریسک و نمودارها.

## امکانات
- **چندکاربره:** هر معامله‌گر ژورنال خودش را دارد و می‌تواند برایش رمز عددی بگذارد.
- **ثبت روزانه:** برنامه روز، کارت هر معامله، یادداشت روز و هشدار اورترید.
- **مدیریت ریسک** مطابق فایل اکسل:
  - سود زیر +2% → ریسک 1%
  - سود بالای +2% → ریسک 1.5%
  - زیر بالانس اولیه → ریسک 0.5%
  - ضرر −10% → توقف

  همه این عددها از تنظیمات قابل تغییرند. بالانس هم به‌صورت مرکب حساب می‌شود.
- **داشبورد:**
  - منحنی سرمایه و دراوداون
  - سود و ضرر ماهانه با وین‌ریت
  - عملکرد استراتژی‌ها، روزهای هفته و نمادها
  - توزیع R
  - وین‌ریت غلتان و وین‌ریت هر ۱۰۰ معامله
  - برنامه در برابر اجرا
  - رشته‌های ضرر پشت‌سرهم
  - پرافیت فاکتور و امید ریاضی
- **ماهانه:** کارت آمار هر ماه (همان JAN STATS اکسل) با پیشرفت تا هدف ماه.
- **اکسل:**
  - ورود فایل بک‌تست با همان قالب `Date | Week Day | Trade 1..3 | Win | Loss | استراتژی 1..3 | توضیحات`
  - خروجی اکسل با شیت‌های ALL، ماه‌ها، Trades و Stats
  - پشتیبان‌گیری و بازیابی JSON

## اجرا
```bash
npm install
npm run dev        # http://localhost:3000
```

## اجرای production روی سرور
```bash
npm install
npm run build
npm start          # پورت 3000
# یا با pm2:
pm2 start npm --name notebook-trade -- start
```
داده‌ها در پوشه `data/` ذخیره می‌شوند: `profiles.json` و یک فایل JSON برای هر ژورنال در `data/journals/`.
برای تغییر مسیر ذخیره، متغیر `DATA_DIR` را تنظیم کن. از این پوشه مرتب نسخه پشتیبان بگیر.

## ساختار
```
app/
  page.tsx                  فهرست ژورنال‌ها + ساخت ژورنال جدید
  journal/[id]/page.tsx     صفحه ژورنال (تب‌ها + ذخیره خودکار)
  api/profiles/...          API: ساخت، خواندن، ذخیره و حذف
components/                 DayEntry، Dashboard، Charts، TradesTable، MonthlyTable، SettingsPanel
lib/
  types.ts                  مدل داده
  stats.ts                  موتور محاسبات (ریسک، بالانس، وین‌ریت، رشته‌ها، ماهانه)
  excel.ts                  ورود و خروج اکسل
  store.ts                  ذخیره‌سازی فایل JSON سمت سرور
```
